| Feature           | NEC                                                      | SIP                                         |
| ----------------- | -------------------------------------------------------- | ------------------------------------------- |
| Gestational age   | <32/40, broad range                                      | Almost always <28/40, ELBW                  |
| Onset             | Week 2-3                                                 | Week 1 (day 3-7)                            |
| Feeding history   | Established enteral feeds                                | Often pre-feeding                           |
| Drug trigger      | None specific                                            | Indomethacin ± early steroids               |
| Pneumatosis       | Yes (pathognomonic)                                      | **No**                                      |
| Portal venous gas | Often                                                    | **No**                                      |
| Pneumoperitoneum  | Late, advanced                                           | Often presenting finding                    |
| Pathology         | Transmural inflammation, coagulative necrosis, extensive | Focal ischaemic necrosis, no inflammation   |
| Location          | Terminal ileum, right colon, can be extensive            | Focal, terminal ileum near ileocaecal valve |
| Abdominal wall    | Erythema                                                 | **Bluish/black discolouration**             |
| Bloody stools     | Common                                                   | Uncommon                                    |
| Prognosis         | Worse                                                    | Better                                      |
